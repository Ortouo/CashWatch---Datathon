## Допуск к демонстрации

Это сценарий для фиксированной версии. Сейчас подтверждены локальные технические UI-проверки на синтетике; Mac startup и видимость журнала сообщены пользователем. Согласованность ключа на Mac нужно подтвердить локально; завершённой проверки сохранения JSON и проигрывания MOV нет. Mac preflight по [VERIFICATION.md](VERIFICATION.md) подтвердил импорты и MPS tiny matmul, но не загрузку модели; FFmpeg/ffprobe отсутствовали. Qwen/CUDA, настоящий MOV-проход, качество, HTTP-время и внешний адрес не подтверждены предоставленными доказательствами. Не называть журнал результатом модели, отметки — эталонной разметкой, а DINO functional fit — качеством конечного API.

До защиты заполнить локально: commit и runtime fingerprint финального запуска [сверить с актуальным отчётом]; browser [на Mac не получено]; фактическая модель/revision/device [не подтверждено]; разрешённые positive/negative примеры [не выбраны]; применимые правила [не допущены]; отчёт независимой оценки [отсутствует]; HTTP-время/hardware [не измерено]; HTTPS адрес [не подтверждён]. Банковские материалы не включать в этот публичный документ.

## Ответы на 2 минуты вопросов

- **Что обучалось?** По переданному отчёту замороженный DINOv2 извлекал признаки, обучены scaler и линейный классификатор на четырёх уникальных видео. Он не интегрирован в API, threshold/quality не подтверждены. Финальный Qwen путь использует pretrained веса; его реальный статус уточнить у Pro 2 перед защитой.
- **Откуда правила и исключения?** Открытые нормативные источники РК, provenance и review Plus 1. Полный текст и применимость к конкретной операции — разные доказательства; три правила остаются выключены до допуска.
- **Как предотвращена утечка?** Дубли и группы исходных сценариев не разделяются между train/validation/holdout. Exposure ledger резервирует четыре использованных SHA, их пять алиасов и связанные сценарии. До подтверждения групп не заявлять независимый holdout.
- **Что при unknown или ошибке?** Ручное unknown не является нормой. Ошибка/неполный отрицательный анализ не подтверждает no_violation. API имеет два verdict для завершённого анализа и отдельный failed; UI явно показывает ошибки.
- **Как измерены пять минут?** Полный HTTP-путь на целевой версии, с upload, очередью, cold start и ответом; сохраняются все ошибки. Сейчас такое измерение отсутствует. Работа timeout не доказывает успешное завершение.
- **Где обрабатываются видео?** Внутри собственного сервиса локальными весами. Для финальной машины нужны реальный прогон и проверка исходящей сети; старый Linux DINO guard не доказывает CUDA/Mac endpoint. Банковские материалы не передаются облачным GPT/API.
- **Почему journal не ground truth?** Это мнение человека, хранимое локально; confirmed не включает правило и не изменяет verdict. Файл требует review и не назначает split автоматически.
