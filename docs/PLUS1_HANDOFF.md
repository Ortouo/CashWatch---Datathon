## Исходная проверка Plus 1 до интеграции

По отчёту Plus 1 выполнено:

```bash
python3 -m unittest discover -s tests -p test_prepare_review.py -v
python3 scripts/prepare_review.py --out local_reports/rules-review-01
python3 -m py_compile scripts/prepare_review.py tests/test_prepare_review.py
git diff --check
```

В исходной версии Plus 1 прошли **четыре синтетических теста**: транзитивная экспозиция и запрет очереди
holdout, конфликт алиасов ledger, побайтовое сохранение исходников/права/отказ
перезаписи, явные unknown-шаблоны при отсутствующих входах. Pytest в исходном
окружении Plus 1 не был установлен; тесты выполнены стандартным unittest. Реальный аудит
42 MOV и метрики качества не запускались. Проверка stdout подтвердила только
агрегаты; игнорирование приватных выходов проверено через git check-ignore.
Эти четыре теста — исторический результат исходной версии, не итоговый счётчик
регрессий объединённого проекта.

## Проверка при локальной интеграции

В `prepare_review.py` защита очереди расширена на всю связанную компоненту
validation/holdout по SHA и известным группам, включая исторические алиасы
ledger. Аудит, хеши и копии входов теперь используют однократно прочитанные
снимки JSON. CLI, приватные права файлов и запрет перезаписи сохранены.
В проектном Python-окружении выполнен целевой синтетический прогон:

```bash
python -m pytest tests/test_prepare_review.py -q
```

Результат после исправлений: **8 passed, 3 subtests passed in 0.04s**;
это проверка инструмента, не человеческого просмотра или качества ИИ.
Review остаётся **0**, допустимых к включению правил — **0**. Интеграционные
изменения здесь описаны локально; публикация этой версии не подтверждена.
