## Контракт и поведение

`POST /api/v1/analyze` принимает multipart `file`, `X-API-Key`, возвращает HTTP 202 с `job_id,status:"processing"`. `GET /api/v1/jobs/{id}` даёт processing, done либо failed. Done содержит `job_id,status,verdict,violations`; событие — `type,timecode_sec,description,evidence_frames`; кадр — `timestamp_sec,image_base64`. Только два verdict: `violation`/`no_violation`. Дополнительная метаинформация — `/details`, доступность модели/правил — `/capabilities`, публичная проверка сервера — `/healthz`.

Сохрани MOV до 100 МиБ, дополнительные расширения только по capabilities, XHR с настоящим upload progress, опрос 1→2 секунды с пределом 300 секунд. Лимит обработки кейса — 5 минут. Остановка ожидания не должна обещать остановку server job. Не скрывай ошибки 401/413/415/429/503. При смене видео отмени старые запросы и исключи смешение результата с другим оригиналом.

Ключ хранится только в памяти; не в URL, логах или browser storage. Запросы только same-origin, без CDN, аналитики и внешних картинок. Сохрани CSP без inline scripts/handlers и вставляй серверные строки через textContent. JPEG из API открывает реальный исходный момент; отдельная кнопка увеличивает кадр. Blob URL освобождается. Источники допускаются только по проверенному HTTPS на `adilet.zan.kz`, с безопасными атрибутами ссылки.

Покажи отдельно «Локальная модель не настроена», «Применимость правил не проверена», отсутствие подтверждённого качества и неполный анализ. Полный официальный текст №231 и текущая редакция подтверждены в [ADILET_PROVENANCE.json](../verification/ADILET_PROVENANCE.json); неизвестна применимость к сценам, поэтому три правила отключены. Unsupported, model missing, incomplete и unknown не превращаются в успешный `no_violation`. На случай `complete:false` убери оформление успешной полной проверки. Не добавляй вымышленные события, проценты уверенности, обученность и показатели качества. Отсутствие необязательного `/details` не должно ломать основной ответ.

Сохрани ручной JSON `kind="cashwatch_manual_review"`, `schema_version=1`, `is_ground_truth=false`: `source` с именем/SHA/размером/длительностью, `group_id`/`camera_id`, `rule_reviews`, `note` и `marks`. `confirmed` — мнение человека о применимости, не verdict и не включение правила; неизвестная длительность — `null`. Записи остаются в памяти страницы, скачиваются локально и не входят в API-запрос; не добавляй импорт, автоматический CSV/manifest, обучение или назначение holdout. SHA-алиасы разделяют draft; пустые группы/камеры и разные ID не доказывают независимость. Отметки плеера не заменяют непрерывный обзор. Проверь смену файлов, восстановление алиаса, ошибки хеша/кодека и экспорт; человек проверяет сохранённый файл до закрытия страницы. JSON содержит приватные имена и заметки, его нельзя отправлять облачным чатам/GitHub.

Пользователь сообщил о запуске; это отдельный источник сведений, не доказательство полного Qwen/MOV-прохода.

Используй искусственные файлы и явно обозначенные подставные ответы для технического QA. Переиспользуй актуальные доказательства уже пройденных проверок; повторяй только затронутые изменениями или остающиеся непроверенными сценарии.

| № | Целевая проверка | Ожидаемый результат |
|---|---|---|
| 1 | Страница, ключ, health/capabilities на Mac | Доступность сервера отделена от модели, правил и конкурсной готовности; ключ не попадает в URL/экспорт. |
| 2 | Выбор одного искусственного исходника | Имя, размер и SHA соответствуют файлу; выбор сам не отправляет видео на анализ. |
| 3 | Журнал при заблокированном анализаторе | Локальные записи доступны без весов; ошибка Web Crypto явно блокирует журнал/экспорт. |
| 4 | Перемотка, marks, неподдерживаемый кодек | Время относится к выбранному источнику; при неизвестной длительности — `null`, добавление отметок недоступно. |
| 5 | unknown/confirmed/not_applicable | Решение человека не меняет verdict, серверный реестр или readiness. |
| 6 | Смена файлов и SHA-алиас | Разные исходники не смешиваются; одинаковые байты восстанавливают общий draft; несохранённый ввод не исчезает молча. |

| 8 | Загрузка, прогресс, ожидание, смена видео | Старый ответ не прикрепляется к новому файлу; отмена ожидания не обещает остановку server job. |

| 10 | Клавиатура и размеры 320/390/1440 px | Доступны фокус, подписи, aria-live, списки журнала и экспорт; длинный синтетический текст не ломает верстку. |
