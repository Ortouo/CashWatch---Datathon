## Базовый запуск Pro 1: настоящий HTTP без ML-зависимостей

README, Makefile и Dockerfile уже использовали эту точку входа. Добавлен отдельный первый этап для Pro 1 на Mac в разделе 0 [MAC_M4.md](MAC_M4.md), уточнён соответствующий промпт.

По `find_spec` подтверждено отсутствие Torch, torchvision, Transformers, Accelerate и huggingface-hub. Затем запущен настоящий Uvicorn-процесс с `app_factory --factory`, одним worker, отдельными runtime и ключом, на loopback-порту; после проверки этот процесс остановлен.

**7 HTTP-проверок прошли, ошибок — 0:** `/healthz` вернул `alive`; отданы настоящие HTML и JS проекта; capabilities без ключа вернул 401; с ключом — 200 и отсутствие ML/весов, ноль активных правил, `ready_for_submission=false`; analyze с ключом отказал кодом 503 при отсутствии модели; analyze без ключа вернул 401. Подставных исполнителей модели не было. Машиночитаемый отчёт: [CORE_START_HTTP.json](verification/CORE_START_HTTP.json).

Это подтверждает базовый путь установки и фактический HTTP-запуск в указанной Linux-среде. Mac пользователя, Windows/WSL, CUDA, банковское видео, модель и публичный endpoint в этой проверке не использовались. Новых результатов точности или GPU-производительности нет.
