## Исправленные риски

**Связанные проверочные видео не должны попасть в настройку правил.** Раньше очередь исключала строку со split validation/holdout, но могла сохранить train-алиас того же SHA либо соседнюю запись связанной группы. Теперь исключается вся транзитивно связанная компонента известных SHA/групп, включая исторические сведения исходного ledger. Скрипт не устанавливает истинность пользовательских групп, не скрывает исходные метаданные от их владельца и не делает оставшуюся выборку автоматически независимой.

**Аудит должен соответствовать сохранённой копии входа.** Manifest и ledger читаются однократно. Изменение файла другим редактором после чтения не меняет уже используемые для SHA, аудита и копии байты. Ошибки необходимых полей и сериализации обнаруживаются до создания выходных файлов. Ограничение JSON — 16 MiB; дубликаты ключей и нечисловые JSON-константы отвергаются.

**Журнал не должен хранить известную ранее длительность после потери metadata.** Используется актуальное значение или null. Ручные отметки остаются мнением пользователя и требуют проверки по источнику. JSON не становится ground truth или разрешением включить правило.
